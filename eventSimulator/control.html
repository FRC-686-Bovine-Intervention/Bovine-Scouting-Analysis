Restart this simulation after a reboot

  1. Open PowerShell in the repository root: D:\FIRST\Scouting\Bovine-Scouting-Analysis.
  2. Start both local services with powershell -ExecutionPolicy Bypass -File .\scripts\start-event-simulator.ps1. Keep that PowerShell window open while testing.
  3. Open http://127.0.0.1:8787/ for this control page and http://127.0.0.1:4174/ for the analysis app. The launcher creates the temporary local routing configuration automatically.
  4. Click Reset timeline, then confirm the state shows cursor: -1 and phase: team-only.
  5. In the analysis app, open Admin Event Control, enter 2026evsim, set the Scouting URL to http://127.0.0.1:8787/api/scouting/2026evsim, set the Scouting Profile URL/path to http://127.0.0.1:8787/api/scouting/2026evsim/schema, and click Load. Leave the TBA auth key blank; simulator-first routing supplies TBA locally.
  6. To prove the apps are connected, click one of the +1, +5, or +10 match buttons here, then click Refresh Sources in the analysis app. The current match and analysis data should update.

Machine check: open http://127.0.0.1:8787/state. It should return JSON with scenario: 2026evsim. Close the launcher PowerShell window when finished.
