We are making an analysis tool for FRC robotics scouting data.  

This analysis tool should be adaptable for use over any FRC season.  

This tool is web-based (though possibly self-hosted) in a framework that works well for any size device such as React Native.  It will support multiple simultaneous users.

The landing page for the app requires the user to login if they haven't already done so.  Login consists of a user name, but no password.  User preferences will be saved.  When logging in, the already existing user list is presented to select from.  The user can also add a new user if they it is not on the existing list.

A toggle at the top of the screen will select between light and dark modes, and the user preference saved for future sessions.

After logging in, the user is presented with the analysis options below.

Input format: give example google spreadsheets

Evaluation Sources:
- Scouter data
- EPA - (https://www.statbotics.io/docs/rest)
- OPR/DPR/CCWM - https://www.thebluealliance.com/apidocs

Evaulation Criteria: 
Many of the evaluation sources can be broken into components parts.  For example, in 2025, the total EPA had component parts for coral, algae, and climb scoring.  The evalution criteria can be changed to either the total score from the evaluation source, or any combination of those components.  

Weighted sums of the source data may be defined to generate evaluation criteria.

Teams are in numerical order, with a thumbnail image taken from their TBA page or from a pit scouting photo, if available.  licking on a team brings up their team summary page.
    - Individual Team page

Picklists:
The user is presented with a list of the saved pick-list for that event (initially empty).  A button is available to Create a new pick list.  When selected, the user is prompted to name the pick list.  Initially, the user creates the pick list by tweaking the evaluation critera.  A Save button is available to store the current list at any time.  As the evaluation criteria is changed, a vertical stack of drag-and-droppable tiles reflects the sorted ranking of the teams present at that event -- best robots at the top of the list.  There are two modes for list manipulation -- changing the evaluation criteria, and dragging-and-dropping.  There should be a selector for changing between these modes.  The mode starts by using the evaluation criteria.  When switching from drag-and-drop to sorted evaluation criteria, the user is warned that any previous list manipulation will be lost.

A user can back out of manipulating a list and return to the main pick list page, which shows a list of the previously saved lists and the Create new list button.


Alliance Selection:
During Alliance Selection, the user is able to load several already-saved Picklists.  Each pick list shows up as a column on the page, in the same tile format as the pick list manipulation, but reordering the lists is not possible here.  On the left hand side of the screen the current alliance selection status is shown with positions for 8 captains, 1st picks, 2nd picks (and additionally 3rd picks at World Champs).   Teams can be dragged and dropped into the alliance selection grid.  Or the user can click into the grid and manuually type the team number.  When a team has been placed into the alliance selection grid, their team number in all displayed Picklists is colored with a dark gray background and the team number is struck-thru.  The pick list tiles should be sized such that at least 24 teams can be displayed vertically at a time.

During pick list viewing (including alliance selection), add indications of sub-par robot to all plots and lists  Ex. inconsistent scoring, possibly broken at end of qualifications, pit scouting indicates non-swerve drivetrain, or is on our Do-Not-Pick list.
